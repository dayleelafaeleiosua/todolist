# To-Do List App

A simple and interactive **To-Do List** web application built with **HTML, CSS, and JavaScript**.

## Features

- Add new tasks  
- Mark tasks as completed  
- Delete tasks  
- Tasks are **saved in localStorage**, so they persist even after refreshing the page  

## Technologies Used

- HTML → Structure  
- CSS → Styling and layout  
- JavaScript → Functionality and localStorage  

## Usage

1. Open `index.html` in a web browser  
2. Type a task in the input field and click **Add Task**  
3. Click a task to mark it as completed  
4. Click the **X button** to delete a task
